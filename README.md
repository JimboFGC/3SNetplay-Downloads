# 3SNetplay downloads

Windows x64 alpha for local-ROM 3rd Strike play using native FBNeo and GGPO rollback.

[Download the launcher](https://github.com/JimboFGC/3SNetplay-Downloads/releases/download/alpha/3SNetplay-Launcher.zip)

Extract the launcher ZIP, then open **Play 3SNetplay**. It downloads and verifies the signed current build. Keep this launcher folder for future updates; your local ROM path and controller settings are preserved.

You need Windows 10/11 x64, Microsoft Edge WebView2, your own compatible local ROMs, and a privately supplied alpha invitation for account registration. No game files are provided or uploaded. For online matches, both players create/join the same private room and choose Connect P2P. Direct P2P exposes your network address to your opponent; an experimental relay is available when direct setup fails.

This repository contains public download materials only. The desktop UI, Rust launcher, accounts and backend source stay private. Required native emulator component and third-party source/notices accompany the runtime download.

## Alpha limits

Router compatibility, physical devices and long-session audio testing remain ongoing. No universal NAT connectivity or perfect worldwide gameplay is promised. Windows publisher signing (Authenticode) is not present; signed update manifests and archive hashes provide a separate integrity check. The first launcher must come from this release page.
